# Personal Expense Tracker

A console-based Personal Expense Tracker developed using **Python**. The project allows users to record, view, edit, and delete expenses while also providing category summaries and budget tracking.

## Project Overview

The Personal Expense Tracker helps users manage their daily expenses through a simple command-line interface. Expense details are stored in a text file so that the data can be loaded again when the program is run.

## Features

* Add new expenses
* View all recorded expenses in a table
* Calculate total expenses
* Display expenses by category
* Check expenses against a monthly budget
* Edit existing expenses
* Delete expenses
* Store expense data using file handling
* Load previously saved expenses automatically

## Technologies Used

* **Programming Language:** Python
* **Concepts:** Lists, Dictionaries, Functions, Loops, Conditional Statements
* **File Handling:** Text file (`expenses.txt`)
* **Interface:** Command-line / Console

## Expense Details

Each expense contains:

* Date
* Amount
* Category

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python main.py
```

5. Select an option from the menu and follow the instructions.

## Main Menu

The program provides the following options:

1. Add Expense
2. View Expenses
3. Show Total Expense
4. Category Summary
5. Check Budget
6. Edit Expense
7. Delete Expense
8. Exit

## File Storage

The program uses `expenses.txt` to store expense information. The file is created automatically when expenses are saved.
